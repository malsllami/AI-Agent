# AI-Agent — مدير المشاريع الذكي

نظام يتابع مشاريع محمد الحالية والمستقبلية، يقرأ حالتها، يكتشف الأخطاء المحتملة والصامتة قبل أن تتفاقم، ويقترح خطط إصلاح وتطوير — بموافقة محمد الصريحة قبل أي تنفيذ فعلي.

## البنية التقنية
- قاعدة البيانات: Google Sheets (ملف "المدير الذكي")
- طبقة الربط: Google Apps Script فقط
- الاستضافة (لاحقًا): GitHub Pages

## هيكلة المشروع
```
gas/                    كود Google Apps Script (الباك إند)
├── Constants.gs        الثوابت: أسماء الأوراق والأعمدة والقيم المسموحة والألوان
├── Formatting.gs       دوال تنسيق مشتركة (رأس ثابت، محاذاة، خط، تحقق صحة، تنسيق شرطي)
├── SheetSetup.gs       دوال إنشاء الجداول (كل دالة مستقلة، إضافة فقط)
└── appsscript.json     ملف إعدادات المشروع (manifest)
```

## قاعدة البيانات
معرف الشيت: `13P7q7k2VuQTBIzqsbOjfBvpVvekRH61jX_wg6XL_O0s`

**ورقة "الرئيسية"** — نظرة عامة على كل المشاريع (الحالة العامة، نسبة السلامة، عدد الأخطاء المفتوحة...).

**ورقة "سجل المراحل"** — مرجع كامل لكل خطة إصلاح متعددة المراحل.

**جدول تفاصيل كل مشروع** — يُنشأ تلقائيًا باسم كل مشروع عند إضافته (عبر الدالة `إنشاء_جدول_تفاصيل_مشروع`)، ويحتوي كل حالة/خطأ مكتشف بنوعه وشدته والخطة المقترحة له وقرار محمد بشأنها.

## الإعداد الأولي
تُشغَّل الدالة `تهيئة_قاعدة_البيانات` مرة واحدة من محرر Apps Script للموافقة على الأذونات وإنشاء الجداول الأساسية. الدالة آمنة للتشغيل أكثر من مرة (لا تكرر الجداول ولا تمسح أي بيانات).
